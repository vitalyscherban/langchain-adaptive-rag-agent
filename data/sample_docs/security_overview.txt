Acme Cloud Platform - Security & Compliance Overview
=====================================================

Data encryption
All customer data is encrypted at rest using AES-256 and in transit using
TLS 1.2 or higher. Encryption keys are managed via a dedicated key management
service (KMS) with automatic key rotation every 90 days.

Access control
Acme Cloud uses role-based access control (RBAC) for all customer accounts.
Administrators can define custom roles with granular permissions scoped to
specific projects, resources, or API actions. Multi-factor authentication
(MFA) is required for all accounts with administrative privileges.

Compliance certifications
Acme Cloud maintains SOC 2 Type II certification, renewed annually through an
independent third-party audit. We are also ISO 27001 certified and undergo
periodic penetration testing by external security firms, with summary reports
available to enterprise customers under NDA.

Incident response
In the event of a security incident affecting customer data, Acme Cloud
commits to notifying affected customers within 72 hours of confirming the
incident, in line with GDPR breach notification requirements. A dedicated
incident response team investigates root cause, containment, and remediation.

Data residency
Customers on Enterprise plans can choose a specific data residency region
(US, EU, or APAC) at account creation time. Changing data residency after
account creation requires opening a migration request with support, since it
involves physically relocating stored data between regions.

Sub-processors
Acme Cloud uses a limited set of vetted sub-processors for infrastructure
hosting and email delivery. The current list of sub-processors is published
on the trust portal and customers are notified of material changes at least
30 days in advance.
